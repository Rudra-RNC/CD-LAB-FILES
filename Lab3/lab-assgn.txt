Recap : 1. The s/w "lex" generates a C file named "lex.yy.c" and defines a function yylex(). The file contains the
constructed DFA and definitions of variables and support functions.The function yylex() performs the role of pattern
recognizer. It is essentially a driver function, that reads input, one character at at time, traverses the dfa in order to detect
whether the input belongs to the language of dfa or not.
2. A single call to yylex() can detect all tokens in the input provided the actions associated with the regexes do not have a
"return". Such use of yylex() is useful only during the development and testing phase of a scanner, but not for deployment.
3. In practice, a scanner is designed to return a single token to its caller. Such a scanner is implemented by inserting a
"return" value at the end of each action and calling yylex() repeatedly till the EOF is reached, such as, "while (yylex());".
4. The order of regexes is important and it decides the final state that is reported by the recognizer.

P3. Applications that examine structured information content, such as logfiles, to detect some unusual patterns that indicate
presence of possible malicious intent, are domains that can benefit from this technology. Consider the directory data
structure in Linux file system, and the command "ls -asl" that accesses the kernel file system data structure to display
several attributes of files and directory resources, $ ls -asl > lsout.txt. Explanation of the symbols used in the display.
type : single letter, "d" denotes a directory and "-" a regular file
permissions : 3 letters from the list {r,w,x,-}, one triple each for {owner, group, others}, total of 9 letters.
"r", "w" and "-" denote read access, write access and no access respectively.
"x" for a file indicates it is executable, for a directory indicates permission to search it.
Hard link count (hlcnt): Number of time a file / dir is listed in the file system.
Assume there are no shared files or directories in the file system,
hlcnt(f) = 1 where f is a file; and hlcnt(d) = 2 + number-of-child-directories(d), for a directory d.
