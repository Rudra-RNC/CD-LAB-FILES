1,2) S → S A | A
3)

| ID
{E.place = newtemp(); gencode (E.place ':=' ID.place);}
A possible implementation of the above SDTS is given in the scripts. The passing of the lexeme for an ID
recognized by the scanner is achieved by i) defining union{} in the yacc scripts and ii) by assigning to yylval the

genlabel(); these functions have been written in a separate file, "tac-functions.c". You may use this file or choose
to replace by your own implementation. Note that file i/o operations are used to append generated TAC to a file
named as, "codefile". The semantic actions use the $-variables to hold and propagate semantic attributes.
